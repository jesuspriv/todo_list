## Description

A Todoist-inspired task manager with project organization, priority levels, and persistent storage. All data is saved to localStorage so tasks survive page reloads.

### Features

- Create and delete **projects** to organize your tasks
- Create, edit, delete, and complete **todos** within each project
- Each todo has: title, description, due date, priority (low/medium/high), and completed status
- **Detail view** — click any task card to see its full information
- **Dashboard** — live stats per project: total, completed, pending tasks, and a progress bar
- Color-coded priority borders on task cards (green / yellow / red)
- Completed tasks visually marked with strikethrough
- Default "General" project created on first load
- Full **localStorage persistence** — data survives page reloads
- Clean sidebar navigation with project list

## Project Structure

```
todo-list/
├── src/
│   ├── index.js        — entry point, app initialization
│   ├── template.html   — base HTML structure
│   ├── styles.css      — all styling
│   ├── Todo.js         — Todo class (title, description, dueDate, priority, completed)
│   ├── Project.js      — Project class (name, todos array, CRUD methods)
│   ├── Storage.js      — localStorage save/load with class reconstruction
│   └── UI.js           — all DOM manipulation and event handling
├── dist/               — compiled output (generated by Webpack)
├── webpack.config.js
├── package.json
└── .gitignore
```

## How to run locally

1. Clone the repository:
```
git clone https://github.com/jesuspriv/todo_odin.git
```

2. Install dependencies:
```
npm install
```

3. Start the dev server:
```
npx webpack serve
```

4. Open `http://localhost:8080` in your browser.

## What I learned

This was the most architecturally complex project of the course — it required careful planning of data structures, separation of concerns, and state management without any framework.

Key concepts practiced:

- **ES6 Classes** — `Todo` and `Project` as proper class instances with methods (`toggleCompleted`, `addTodo`, `removeTodo`)
- **Separation of concerns** — logic (`Todo`, `Project`), persistence (`Storage`), and display (`UI`) are completely separate modules
- **localStorage persistence** — serializing class instances to JSON and reconstructing them on load (re-instantiating with `new` to restore methods)
- **ES6 modules** — `import`/`export` across multiple files via Webpack
- **DOM manipulation** — dynamic rendering of projects and todos, no hardcoded HTML
- **Event delegation and stopPropagation** — preventing card click from firing when buttons inside are clicked
- **State management** — `activeProject` and `activeTodo` variables to track current context across events
- **Dashboard stats** — real-time calculation of completed/pending tasks and progress bar
